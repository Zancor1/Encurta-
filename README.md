# Encurtaí

Transforme links longos em endereços curtos, fáceis de copiar e compartilhar.

**[Abrir o Encurtaí](https://encurta-a698.onrender.com/)**

Para usar online, abra o site, cole seu link e clique em **Encurtar link**. Depois é só copiar e compartilhar. Não precisa instalar nada nem deixar o painel do Render aberto.

## Rodar no computador

Você precisa do Python 3.10 ou mais recente.

1. Baixe este repositório e abra um terminal na pasta do projeto.
2. Instale as dependências:

```sh
python -m pip install -r requirements.txt
```

3. Inicie o servidor:

```sh
python server.py
```

4. Abra http://localhost:8000 no navegador.

Deixe o terminal aberto enquanto usa a versão local. Para encerrar, pressione **Ctrl+C**. Links criados em localhost funcionam apenas no seu computador; para compartilhar com outras pessoas, use o site online.
